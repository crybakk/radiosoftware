## Regia

- Prima di aggiornare, il pulsante "Cosa cambia?" mostra l'elenco delle novità della versione nuova.
- Dopo l'aggiornamento, alla prima apertura la regia mostra cosa è cambiato, finché non premi "Ho letto".
- Se una versione nuova cambia solo il server, la regia non propone più di aggiornarsi (in Impostazioni lo dice).

## Server

- Il pannello mostra le novità del server prima di aggiornare e, dopo l'aggiornamento, cosa è cambiato finché un
  amministratore non preme "Ho letto".
- Se una versione nuova cambia solo la regia, il server non propone più di aggiornarsi.
