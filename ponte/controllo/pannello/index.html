                              Impostazioni del server

                              Quando salvi, il server riparte da solo soltanto nelle parti che usano i valori cambiati. Le password non si vedono: lasciale vuote per tenere quelle di adesso.

                              Collega la regia dello studio

                              Copia questo codice e incollalo nella regia (alla prima accensione, oppure in Impostazioni → Avanzate → Collegamento). Contiene le password del collegamento: non mandarlo a chi non deve usare la regia.

                              Avanzate

                              Se sbagliati, la regia o il pannello non si collegano più. Di solito vanno cambiati anche nella regia, sul router o nelle app delle esterne.

                              Annunci vocali del server

                              Annunci a orario letti dalla voce sintetica, solo quando trasmette il server (diretta autonoma o musica di riserva): vanno in onda dopo il brano in corso. Quando c'è la regia gli annunci li fa la regia con i suoi eventi.
